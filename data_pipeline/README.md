# CIRA dataset pipeline

Builds the controlled, pixel-preserving food-scene dataset: background + left plate + right
plate at fixed slots; every edit swaps exactly one layer; nothing is regenerated by a model.
All constants are in `config.yaml`; open items are marked `OPEN ITEM` there and in `classes.py`.

## Run order

```bash
export CIRA_DATA_ROOT=/work/pi_xxx/cira          # default: ./data
python -m data_pipeline.classes                  # print/validate the class -> region table
python -m data_pipeline.crops extract            # GPU (slurm STEP=crops)
python -m data_pipeline.crops qwen-check         # GPU (slurm STEP=qwen) - logged exception
python -m data_pipeline.crops finalize
python -m data_pipeline.crops report             # rejection table + crops/contact_sheet.jpg
python -m data_pipeline.backgrounds fetch        # internet (login node)
python -m data_pipeline.backgrounds audit        # GPU (slurm STEP=bgaudit)
python -m data_pipeline.backgrounds report       # counts + backgrounds/contact_sheet.jpg
python -m data_pipeline.splits assign            # split ownership of photos/backgrounds + held-out pairings
python -m data_pipeline.groups                   # group recipes  groups/<split>.jsonl
python -m data_pipeline.questions                # 21 cells/group questions/<split>.jsonl
python -m data_pipeline.questions --show g000000 # print one group's 21 cells
python -m data_pipeline.splits verify
python -m data_pipeline.render --split train     # (slurm array STEP=render), all 4 splits
python -m data_pipeline.render --demo group.png  # 7 images side by side
python -m data_pipeline.audit controls
python -m data_pipeline.audit checks --use_saved # full dataset; must PASS
CIRA_TEST_FULL=1 pytest -q tests                 # same tests over every real group
python -m data_pipeline.audit human-export       # audit/human_audit.html -> fill -> ingest
python -m data_pipeline.audit human-ingest results.csv
python -m data_pipeline.freeze                   # needs benchmark_name, passing checks, git commit
```

`pytest -q` alone runs everything on a synthetic dataset (no GPU, no downloads).

Local laptop demo (small models, one HF parquet shard, pilot backgrounds):
`--config data_pipeline/config.demo.yaml`.

## Guarantees and where they are enforced

| Guarantee | Enforced in |
|---|---|
| Edits change only the swapped layer's pixels (slot box and plate mask); bg swaps never touch opaque plate pixels | `render.py` design; `audit.check_group_pixels`; `tests/test_pixel_preservation.py` (all pairs, all groups) |
| t-then-o == o-then-t == fresh render | `audit.check_commutativity` |
| Byte-identical re-renders | `audit.run_checks`, `test_determinism_bytes`; `--use_saved` compares saved PNGs to re-renders |
| Answers mechanical, options shared across 7 images, relevance = spec table | `audit.check_labels`, `tests/test_labels.py` |
| No photo/background in >1 split, held-out classes only in test_unseen, held-out pairings not in train, no cross-split near-duplicates | `splits.verify`, `tests/test_splits.py` |
| Frozen content can't change without a version bump | `freeze.py` |
